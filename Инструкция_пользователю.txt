================================================================================
  PoverkiVSE — инструкция для пользователя (первое получение программы)
================================================================================

Организация: Служба скорой медицинской помощи (учёт поверок алкометров и тонометров).


── Вариант А: вы получили только файл PoverkiVSE.exe ─────────────────────────

1. Создайте папку на компьютере (удобно: «Документы» или отдельный диск), 
   например: PoverkiVSE.

2. Скопируйте в неё файл PoverkiVSE.exe (и при наличии — README.txt и этот файл).

3. Запустите PoverkiVSE.exe двойным щелчком.

   При первом запуске программа САМА создаст рядом с exe папки:
     • data   — здесь будет база данных (orchestrator.db)
     • documents — сюда сохраняются файлы, прикреплённые к приборам

4. Если Windows предупреждает о «неизвестном приложении» — для программ без 
   цифровой подписи это бывает нормально. При необходимости: 
   «Подробнее» → «Выполнить в любом случае» (текст может отличаться в вашей 
   версии Windows).


── Вариант Б: вы получили архив (ZIP и т.п.) с exe и папками data и documents ─

1. Распакуйте ВЕСЬ архив в одну папку так, чтобы рядом лежали:
     PoverkiVSE.exe
     папка data
     папка documents

   Дополнительно создавать папки вручную не нужно — они уже в комплекте.

2. Запустите PoverkiVSE.exe из этой папки.

   Если какой-то папки не оказалось, при следующем запуске программа может 
   создать недостающую автоматически (как в варианте А).


── Важно сохранять ───────────────────────────────────────────────────────────

  • Папку data — в ней журнал и настройки в базе. Копируйте её для резервной 
    копии учёта.

  • Папку documents — прикреплённые документы к приборам.

  Не удаляйте их без необходимости и согласования с администратором.


── Справка в программе ──────────────────────────────────────────────────────

  В правой панели «Действия» нажмите «Справка» — откроется подробная справка 
  в браузере.

  • Проверьте, не блокирует ли антивирус — при необходимости добавьте папку с
