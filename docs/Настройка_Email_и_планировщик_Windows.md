# Настройка Email (SMTP) и планировщика Windows

## Шаг 1 — После `git pull`

В терминале в **корне проекта** (`orchestrator_tonometr`):

```bat
git pull
python db\migrate_email.py
python notify_daily.py --dry-run
```

**Ожидаемо в консоли:** сводный текст в dry-run, строки `notify_daily MAX: sent=…` (число получателей MAX) и `notify_daily Email: …`.  
Письмо — **одна сводка** на **Email администратора**; без адреса будет `skipped=1`. Повтор в тот же день не шлётся (`skipped_already_today` в логе).

---

## Шаг 2 — SMTP в GUI

1. `python main.py`
2. Боковая панель → **📨 Email-уведомления**
3. Выберите провайдера (Mail.ru / Яндекс / Gmail), заполните **логин** и **пароль приложения** (не основной пароль)
4. Поле **Email администратора** — сюда приходит **ежедневная сводная ведомость** (стадии, сроки, таблица по ответственным)
5. **💾 Сохранить SMTP**
6. В **«Отправить тест на:»** введите свой адрес → **🔌 Тестовое письмо** → проверьте почту (тема: `✅ Тест SMTP — Оркестратор Поверки`)

---

## Шаг 3 — Справочник email ответственных

Таблица **ФИО** / **Email** — для учёта в базе (на сводку по почте не влияет).  
**📤 Отправить сводку администратору** — одно письмо на адрес администратора (как при ежедневном `notify_daily`).

Повторная **email-сводка** в тот же день не отправляется (`notification_log`, канал `email_digest`).  
**MAX:** сводка каждому получателю не чаще раза в день (`MAX_digest` + `chat_id`).

## Планировщик заданий Windows

1. **Пуск** → **Планировщик заданий** → **Создать задачу…**
2. **Триггер:** ежедневно, например 09:00
3. **Действие:** запуск программы:
   - **Вариант A:** программа `C:\Users\...\orchestrator_tonometr\scripts\run_notify_daily.bat`  
     (папка «Начать в» можно оставить пустой — bat сам переходит в корень проекта)
   - **Вариант B:** программа `python.exe` с полным путём  
     аргументы: `C:\Users\...\orchestrator_tonometr\notify_daily.py`  
     **«Начать в»:** `C:\Users\...\orchestrator_tonometr`
4. Отметьте **Выполнять для пользователя, вошедшего в систему** (или настройте учётную запись с доступом к БД и сети)

Лог: `logs\notify.log` в корне проекта.

Проверка без отправки: запустите вручную `scripts\run_notify_daily_dry_run.bat`.
