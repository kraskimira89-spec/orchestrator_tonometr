================================================================================
  PoverkiVSE — кратко о первом запуске
================================================================================

1. Положите PoverkiVSE.exe в отдельную папку на диске (не запускайте из архива 
   без распаковки).

2. Запустите PoverkiVSE.exe.

   • Если рядом УЖЕ есть папки «data» и «documents» (например, вы распаковали 
     полный комплект из архива) — просто работайте как обычно.

   • Если у вас только один файл .exe — при первом запуске программа сама 
     создаст папки data и documents рядом с exe.

3. Подробная пошаговая инструкция, резервное копирование и контакты — в файле 
   «Инструкция_пользователю.txt» в этой же папке.

4. Внутри программы: кнопка «Справка» на правой панели — полное руководство 
   в браузере.
